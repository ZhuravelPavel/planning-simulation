# The parts, named

Short definitions for the objects in the three guides. The guides explain how they fit together. This page only fixes the names.

| Name | What it is |
| --- | --- |
| Publisher | A site inside Revive. IsexyChat is isexychat.com. BDSMLR is bdsmlr.com. |
| Zone | A place on a page that asks Revive for an ad. |
| Campaign | An advertiser’s line of creatives inside Revive. |
| Banner | One creative. Also the name of the ordinary display format. |
| Tabunder | An ad that opens in a new tab, usually as the current tab closes. Older name: popunder. |
| Interstitial | A full-page ad between actions. |
| Fill | The share of zone requests that received a creative. |
| Deal CPM | The price in the contract, per thousand impressions. |
| eCPM | A yield Revive calculates. Not the figure that goes in the sheet or on an invoice. |
| Revenue share | The partner pays a share of what they earn from the visitor. The dollars come from their statement. |
| Sheet | The daily commercial book for one property. iSexyChat from 2019. BDSMLR from 2021, including the shop. |
| Shop | shop.bdsmlr.com. PayPal. The older paid membership. Not a Revive advertiser. |
| Logged in | Whether the person was authenticated when something was measured. It does not identify them. |
| Direct payment | Money a person pays the company for a product. Not a fee to remove ads, and not an advertising line. |
| Shared membership | One payment that can unlock more than one property. Each property keeps its own user account. Billing is a separate account. |
| Room | A destination page that owns a search query. The home page is not that page. |
| Canonical | The one URL a page claims as itself. Search is pointed there and nowhere else. |
| Search Console | Google’s count of clicks, impressions, and position. |
| Ahrefs | A count of which URL ranks for which keyword. Used to see assignment, not to replace Search Console clicks. |
| Key event | A GA4 action defined as a result, such as a signup or a chat starting. Distinct from an ordinary page view. |
